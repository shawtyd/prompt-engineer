# Promptimizer

**Optimize the prompt. Preserve the intent.**

Promptimizer is an AI Prompt Engineering platform that helps users communicate effectively with AI by transforming rough, incomplete, or unstructured prompts into optimized prompts — while teaching the principles behind every improvement.

## What's Inside

### Claude Code Skill

A production-ready Claude Code Skill (`.claude/skills/promptimize-skill/SKILL.md`) that functions as a professional AI Prompt Engineering coach. It understands user intent, confirms before optimizing, and teaches Prompt Engineering concepts through every interaction.

### Dashboard

An interactive web interface (`dashboard/index.html`) that provides:

- Distraction-free prompt editor
- Intent confirmation before optimization
- Prompt quality scoring across 8 dimensions
- Detailed improvement breakdowns
- Technique explanations
- Personalized coaching feedback

## Philosophy

Most users don't think in prompts. They think in ideas, goals, problems, and desired outcomes. Promptimizer translates those thoughts into prompts that AI systems can understand more accurately — without ever changing what the user wants.

## Prompt Engineering Principles

Promptimizer applies established techniques from Anthropic, OpenAI, Google, Microsoft, DeepLearning.AI, and Hugging Face documentation:

- Intent Preservation
- Role Prompting
- Context Injection
- Constraints and Boundaries
- Output Formatting
- Success Criteria
- Audience Definition
- Task Decomposition
- Few-Shot Prompting
- Specificity and Precision
